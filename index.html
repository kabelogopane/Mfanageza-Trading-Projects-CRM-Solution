Questions

Good to know.

Here are a few quick answers before you start your application.

Where do I submit my application?

Select Start your application or Candidate Portal. You will be taken to the secure Salesforce candidate experience once it has been configured.

What is an application reference?

It is the reference number linked to your application. Keep it safe so you can return to your application journey.

Where are my application details stored?

The public website is only the entry point. Candidate records and application information are intended to be managed securely in Salesforce.

Is this website connected directly to Salesforce?

No private Salesforce credentials are stored here. The site hands candidates to the Salesforce Experience Cloud portal, which is the planned secure connection layer.
